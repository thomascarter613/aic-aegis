# WP-E0-001 — Product Charter

## Objective

Define the product charter for AIC Aegis.

## Deliverables

- product statement
- target user
- MVP wedge
- non-goals
- first workflow
- acceptance criteria

## Acceptance criteria

- Aegis is clearly defined as an AI Reliability Control Plane.
- MVP scope is bounded.
- First workflow is selected.
- Non-goals are explicit.
- The charter can be used to generate epics and GitHub issues.
