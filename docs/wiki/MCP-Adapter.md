# MCP Adapter

Model Context Protocol as an integration layer later.

---

## Purpose

MCP Adapter defines how Aegis may integrate with MCP.

---

## Rule

MCP is an adapter, not the domain core.

MCP tools must still pass through:

* Tool Broker,
* policy,
* approval,
* result filtering,
* evidence.

---

## MVP Position

MCP is not required for MVP-A.

Synthetic tools come first.

---

## North Star

MCP can expand integrations without weakening Aegis governance.
