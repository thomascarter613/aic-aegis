# Privacy Rules

Redaction, sensitive data, and memory governance.

---

## Purpose

Privacy Rules define how Aegis protects sensitive information.

---

## Rules

1. Use synthetic data in MVP demos.
2. Classify sensitive data.
3. Redact evidence exports.
4. Do not expose secrets to models.
5. Govern memory admission.
6. Enforce tenant scope.
7. Expire or delete memory when required.

---

## North Star

Privacy rules help AI work safely with business data.
