# Observability Architecture

Logs, metrics, traces, evidence, and events.

---

## Purpose

Observability Architecture defines how Aegis sees itself.

---

## Observability Signals

| Signal   | Purpose                |
| -------- | ---------------------- |
| Logs     | Operational details    |
| Metrics  | Counts, rates, latency |
| Traces   | Cross-system execution |
| Events   | Domain timeline        |
| Evidence | Human-readable proof   |

---

## Rule

Observability supports evidence but does not replace it.

---

## North Star

Observability helps operate Aegis; evidence helps trust Aegis.
