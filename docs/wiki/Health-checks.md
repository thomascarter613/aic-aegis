# Health Checks

Service health expectations.

---

## Purpose

Health Checks define how Aegis reports operational readiness.

---

## Health Areas

* API alive,
* database reachable,
* worker alive,
* policy adapter reachable,
* queue reachable,
* evidence generator available,
* model adapter available.

---

## MVP Scope

MVP should include basic API and database health checks.

---

## North Star

Health checks make operational failure visible.
