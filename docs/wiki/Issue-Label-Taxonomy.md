# Issue Label Taxonomy

GitHub labels and meanings.

---

## Purpose

Issue labels help organize Aegis work.

---

## Recommended Labels

| Label          | Meaning             |
| -------------- | ------------------- |
| `epic`         | Large body of work  |
| `work-packet`  | Scoped unit of work |
| `task`         | Implementation task |
| `docs`         | Documentation       |
| `architecture` | Architecture change |
| `schema`       | Schema or contract  |
| `policy`       | Policy-related      |
| `tooling`      | Developer tooling   |
| `security`     | Security-related    |
| `evidence`     | Evidence-related    |
| `evals`        | Evaluation-related  |
| `memory`       | Memory governance   |
| `runtime`      | Runtime             |
| `outcome`      | Business outcome    |
| `blocked`      | Cannot proceed      |

---

## North Star

Labels make work easier for humans and AI agents to navigate.
