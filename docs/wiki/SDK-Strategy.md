# SDK Strategy

TypeScript and Python SDKs later.

---

## Purpose

SDK Strategy defines future developer interfaces.

---

## Future SDKs

Aegis may support:

* TypeScript SDK,
* Python SDK.

---

## SDK Capabilities

SDKs may support:

* create run,
* get timeline,
* fetch evidence,
* submit feedback,
* record outcomes,
* register tools later.

---

## MVP Position

SDKs are not required before the API works.

---

## North Star

SDKs should make governed AI workflows easy to integrate.
