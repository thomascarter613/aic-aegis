# Rejected Alternatives

Ideas considered and intentionally rejected.

---

## Purpose

Rejected Alternatives preserve why certain paths were not chosen.

---

## Initial Rejections

| Alternative                    | Reason                                          |
| ------------------------------ | ----------------------------------------------- |
| Generic chatbot framework      | Too narrow and not governance-first             |
| Prompt library                 | Does not solve operational trust                |
| RAG-only app                   | Memory/retrieval is not enough                  |
| Direct agent-to-tool execution | Unsafe and unauditable                          |
| Microservices-first MVP        | Too much operational complexity too early       |
| Vector DB as truth layer       | Vectors help find truth, but do not store truth |
| Compliance dashboard only      | Aegis must enforce runtime controls             |

---

## North Star

Rejected Alternatives prevent repeated drift into weaker product shapes.
