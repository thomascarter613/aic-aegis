# Contributing-Guide

How humans contribute.

---

## Purpose

Contributing Guide explains how humans should contribute to Aegis.

---

## Contribution Flow

1. Read Start Here.
2. Check Project Status.
3. Choose issue or work packet.
4. Create branch.
5. Make scoped change.
6. Run tests.
7. Update docs.
8. Open PR.

---

## Rule

Contributions must preserve Aegis Laws.

---

## North Star

Contributing should improve Aegis without weakening governance.
