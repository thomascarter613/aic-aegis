# Documentation-Standards

How docs should be written.

---

## Purpose

Documentation Standards keep Aegis docs useful.

---

## Rules

1. Use clear headings.
2. Define purpose.
3. State scope.
4. Include rules.
5. Include MVP notes.
6. Link related pages.
7. Avoid unsupported claims.
8. Update docs with code changes.

---

## North Star

Docs should help humans and AI agents preserve project intent.
