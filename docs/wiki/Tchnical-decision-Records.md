# Technical Decision Records

Engineering-level decisions.

---

## Purpose

Technical Decision Records capture implementation choices that are not broad enough for ADRs but still important.

---

## Examples

Use Technical Decision Records for:

* package choices,
* library choices,
* schema tooling,
* test approach,
* migration tool,
* local dev setup,
* service layout,
* queue approach.

---

## Rule

Technical decisions should not contradict ADRs, Aegis Laws, or Architecture Doctrine.

---

## North Star

Technical Decision Records keep engineering choices reviewable.
