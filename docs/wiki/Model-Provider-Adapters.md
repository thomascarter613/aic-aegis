# Model Provider Adapters

OpenAI, local models, mock provider, and future providers.

---

## Purpose

Model Provider Adapters isolate Aegis from model-specific SDKs.

---

## Adapter Types

* mock model provider,
* local model provider,
* OpenAI adapter later,
* other provider adapters later.

---

## MVP Scope

MVP-A should start with a mock model provider.

---

## Rule

Model SDKs belong in adapters, not domain core.

---

## North Star

Model adapters let Aegis govern AI work across providers.
