# Control Catalog

Controls Aegis implements or plans to implement.

---

## Purpose

Control Catalog maps risks to controls.

---

## Initial Controls

| Control                | Risk Addressed        |
| ---------------------- | --------------------- |
| Tool Broker            | Direct tool execution |
| Memory Admission Gate  | Memory poisoning      |
| Policy Decision Record | Policy opacity        |
| Evidence Pack          | Lack of auditability  |
| Tenant Scope           | Cross-tenant leakage  |
| Approval Gate          | High-risk action      |
| Eval Gate              | Regression            |
| Outcome Record         | ROI overclaim         |
| Redaction              | Data leakage          |

---

## North Star

Controls are how Aegis turns risk awareness into system behavior.
