# Architecture-Review-Checklist

Architecture gate before major changes.

---

## Checklist

* Preserves Architecture Doctrine.
* Preserves Aegis Laws.
* Domain core remains infrastructure-free.
* Uses ports/adapters.
* Avoids premature microservices.
* Maintains tenant isolation.
* Does not bypass policy/tool/memory governance.
* Evidence path remains clear.

---

## North Star

Architecture review prevents drift.
