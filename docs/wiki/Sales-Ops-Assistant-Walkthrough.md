# Sales-Ops-Assistant-Walkthrough

Step-by-step golden workflow walkthrough.

---

## Steps

1. User submits synthetic conversation.
2. Aegis creates Run Envelope.
3. Runtime calls mock model.
4. Model returns summary and proposals.
5. Tool Broker receives proposals.
6. Policy allows low-risk tools.
7. Policy blocks or approval-gates `email.send`.
8. Evidence Pack is generated.
9. Eval result is recorded.
10. Feedback is captured.
11. Outcome is recorded.

---

## Expected Result

Safe work proceeds.

Risky work is governed.

Evidence proves it.

---

## North Star

The walkthrough should make Aegis understandable in one demo.
