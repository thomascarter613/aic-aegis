# Runbooks

Operational response guides.

---

## Purpose

Runbooks define what to do when something fails.

---

## Initial Runbooks

* API unavailable,
* database unavailable,
* policy adapter failure,
* evidence generation failure,
* tool execution failure,
* eval failure,
* queue failure,
* high-risk tool incident.

---

## North Star

Runbooks make incident response repeatable.
