# Release Plan

How versions are cut.

---

## Purpose

Release Plan defines how Aegis versions are prepared and shipped.

---

## Early Release Milestones

| Release | Meaning                         |
| ------- | ------------------------------- |
| `0.0.x` | Foundation docs and scaffolding |
| `0.1.0` | MVP-A Proof Loop                |
| `0.2.0` | MVP-B Learning Loop             |
| `1.0.0` | First stable v1 control plane   |

---

## Release Checklist

Before release:

* tests pass,
* docs updated,
* changelog updated,
* schemas versioned,
* acceptance criteria met,
* known risks documented,
* evidence examples generated.

---

## North Star

Releases should mark verified progress, not arbitrary snapshots.
