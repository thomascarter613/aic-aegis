# CI Guide

GitHub Actions and required checks.

---

## Purpose

CI Guide defines automated checks for Aegis.

---

## Planned Checks

* install dependencies,
* lint,
* format check,
* unit tests,
* integration tests,
* schema validation,
* docs checks,
* security scans later,
* eval smoke tests later.

---

## MVP Scope

MVP-A CI should at least run:

* tests,
* lint,
* schema validation,
* docs link checks if available.

---

## North Star

CI protects Aegis from regressions.
