# Operations Overview

How Aegis should be operated.

---

## Purpose

Operations Overview defines how Aegis should be run and maintained.

---

## Operational Responsibilities

Aegis operations should cover:

* service health,
* run failures,
* policy failures,
* tool failures,
* evidence generation,
* eval failures,
* backups,
* incidents,
* cost tracking.

---

## MVP Scope

MVP should support local operation and clear debugging.

---

## North Star

Operations should make Aegis reliable in practice, not just design.
