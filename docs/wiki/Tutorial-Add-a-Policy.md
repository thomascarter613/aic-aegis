# Tutorial-Add-a-Policy

Policy pack flow.

---

## Goal

Add a runtime policy.

---

## Steps

1. Define policy purpose.
2. Define checkpoint.
3. Define decision values.
4. Implement mock or OPA rule.
5. Add tests.
6. Record policy decision.
7. Link decision to evidence.

---

## North Star

Policies should execute, not merely document intent.
