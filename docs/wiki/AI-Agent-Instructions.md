# AI-Agent-Instructions

Rules for AI coding agents.

---

## Purpose

AI Agent Instructions define how AI agents should work in the repo.

---

## Rules

AI agents must:

* follow work packets,
* avoid inventing direction,
* preserve architecture doctrine,
* update docs,
* keep changes scoped,
* avoid bypassing governance,
* respect tests and acceptance criteria.

---

## Forbidden

AI agents must not:

* bypass Tool Broker,
* bypass policy,
* bypass Memory Admission Gate,
* skip evidence,
* claim outcomes without records.

---

## North Star

AI agents should help build Aegis according to Aegis rules.
