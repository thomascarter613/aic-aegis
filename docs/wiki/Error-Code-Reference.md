# Error Code Reference

Future structured errors.

---

## Purpose

Error Code Reference will define structured Aegis error codes.

---

## Future Error Families

* `RUN_ERROR`,
* `TOOL_ERROR`,
* `POLICY_ERROR`,
* `MEMORY_ERROR`,
* `EVIDENCE_ERROR`,
* `EVAL_ERROR`,
* `APPROVAL_ERROR`,
* `OUTCOME_ERROR`,
* `TENANT_ERROR`.

---

## Rule

Errors should become events when relevant.

No silent failure.

---

## North Star

Structured errors make failures visible and correctable.
