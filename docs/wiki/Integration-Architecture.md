# Integration Architecture

Adapter-first integration model.

---

## Purpose

Integration Architecture defines how Aegis connects to external systems.

---

## Core Rule

External systems are adapters.

They must not define the domain core.

---

## Integration Types

* model providers,
* tools,
* policy engines,
* memory stores,
* telemetry,
* webhooks,
* SDKs,
* MCP servers.

---

## North Star

Integration Architecture keeps Aegis provider-neutral and governable.
