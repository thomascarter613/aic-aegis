## Purpose

The Task Index tracks concrete implementation tasks.

---

## Task Fields

Each task should include:

* task ID,
* title,
* epic,
* work packet,
* status,
* owner,
* files affected,
* acceptance criteria,
* test requirements,
* related issue.
