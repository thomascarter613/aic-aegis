# Tutorial-Add-a-Tool

Tool manifest and broker flow.

---

## Goal

Add a synthetic tool to Aegis.

---

## Steps

1. Create Tool Manifest.
2. Add tool to registry.
3. Define risk class.
4. Add synthetic adapter.
5. Route proposal through Tool Broker.
6. Verify policy decision.
7. Verify evidence.

---

## North Star

Adding a tool should never bypass governance.
