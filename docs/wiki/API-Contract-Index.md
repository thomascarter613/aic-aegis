# API Contract Index

API endpoints and versioning.

---

## Purpose

The API Contract Index lists current and planned Aegis API contracts.

---

## Planned API Areas

| Area     | Purpose                              |
| -------- | ------------------------------------ |
| Runs     | Create and inspect governed runs     |
| Timeline | Retrieve run timeline                |
| Tools    | Register and inspect tools           |
| Policy   | Retrieve policy decisions            |
| Evidence | Generate and retrieve Evidence Packs |
| Evals    | Run and retrieve evals               |
| Feedback | Submit feedback                      |
| Outcomes | Record and retrieve outcomes         |
| Memory   | Retrieve and admit memory later      |

---

## Versioning Rule

APIs should be versioned.

Breaking changes should not be silent.

---

## MVP Scope

MVP-A needs:

* create run,
* get run,
* get timeline,
* get evidence pack.

---

## North Star

API contracts make Aegis usable as a headless control plane.
