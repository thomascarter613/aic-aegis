# Linting and Formatting

Code quality rules.

---

## Purpose

Linting and Formatting keep the codebase consistent.

---

## Rules

1. Formatting should be automated.
2. Lint failures should block CI.
3. Generated files should be clearly marked.
4. Style choices should be documented.
5. AI-generated code must pass the same checks.

---

## MVP Scope

Add lint and format scripts once language/tooling is selected.

---

## North Star

Code quality rules reduce noise and improve maintainability.
