# policy-decision-reference

Decision values and semantics.

---

## Decisions

| Decision           | Meaning               |
| ------------------ | --------------------- |
| `allow`            | Proceed               |
| `deny`             | Do not proceed        |
| `require_approval` | Pause for approval    |
| `sanitize`         | Transform data        |
| `redact`           | Remove sensitive data |
| `escalate`         | Higher review         |
| `defer`            | Postpone              |
