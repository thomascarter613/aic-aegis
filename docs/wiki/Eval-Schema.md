# Eval Schema

Eval cases, eval packs, eval runs, eval results.

---

## Purpose

Eval Schema defines how Aegis measures behavior.

---

## Eval Case

Includes:

* eval case ID,
* workflow ID,
* input reference,
* expected behavior,
* scoring rubric,
* risk area,
* version.

---

## Eval Pack

Includes:

* eval pack ID,
* eval case IDs,
* workflow ID,
* version,
* status.

---

## Eval Result

Includes:

* eval result ID,
* eval case ID,
* run ID,
* score,
* passed,
* dimensions,
* notes,
* evidence pack ID.

---

## North Star

Eval Schema lets Aegis evaluate and improve AI behavior.
