# Abuse Cases

How Aegis could be misused and how to prevent it.

---

## Purpose

Abuse Cases identify misuse scenarios.

---

## Abuse Cases

| Abuse Case                          | Control            |
| ----------------------------------- | ------------------ |
| AI sends unauthorized email         | Approval gate      |
| AI accesses another tenant memory   | Tenant isolation   |
| AI stores false memory              | Admission gate     |
| AI leaks sensitive data in evidence | Redaction          |
| AI bypasses policy                  | Policy checkpoints |
| AI claims false ROI                 | Outcome records    |
| AI executes unmanifested tool       | Tool Broker        |

---

## North Star

Abuse Cases help Aegis design controls before harm occurs.
