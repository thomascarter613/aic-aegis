Required review checks.

## Checklist

* Scope matches issue/work packet.
* Tests pass.
* Docs updated.
* Schemas updated if needed.
* Aegis Laws preserved.
* Domain core remains clean.
* Tool Broker not bypassed.

* Evidence implications addressed.
* Tenant isolation preserved.
