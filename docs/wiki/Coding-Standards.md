# Coding-Standards

Language and style standards.

---

## Purpose

Coding Standards define how code should be written.

---

## Standards

1. Keep domain core clean.
2. Use clear names.
3. Prefer small modules.
4. Validate schemas.
5. Write tests.
6. Avoid hidden side effects.
7. Preserve tenant scope.
8. Record important events.

---

## North Star

Code should make governance obvious.
