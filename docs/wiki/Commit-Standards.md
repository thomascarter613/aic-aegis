# Commit-Standards

Commit message format.

---

## Purpose

Commit Standards make history readable.

---

## Suggested Format

```text
type(scope): summary
```

Examples:

* `docs(wiki): add memory governance pages`
* `feat(runtime): add run envelope`
* `test(policy): add high-risk tool tests`

---

## Types

* feat,
* fix,
* docs,
* test,
* refactor,
* chore,
* ci,
* security.

---

## North Star

Commits should explain what changed and why.
