# Definition of Done

Project-wide completion criteria.

---

## Purpose

Definition of Done defines what must be true before work is accepted.

---

## Done Checklist

Work is done when:

1. acceptance criteria are satisfied,
2. tests pass,
3. architecture rules are preserved,
4. docs are updated,
5. schemas are consistent,
6. no Aegis Laws are violated,
7. security implications are considered,
8. evidence or audit implications are addressed,
9. code is reviewable,
10. decisions are recorded if needed.

---

## North Star

Done means correct, tested, documented, and aligned with Aegis doctrine.
