# Scripts

What each script does.

---

## Purpose

Scripts help contributors run repeatable tasks.

---

## Planned Scripts

| Script          | Purpose                  |
| --------------- | ------------------------ |
| `doctor.sh`     | Validate local setup     |
| `dev.sh`        | Start local dev services |
| `test.sh`       | Run tests                |
| `lint.sh`       | Run lint checks          |
| `format.sh`     | Format code              |
| `db-migrate.sh` | Run migrations           |
| `demo.sh`       | Run golden workflow demo |

---

## Script Rule

Scripts should be safe, documented, and local-first.

---

## North Star

Scripts reduce setup friction and make AI-agent execution repeatable.
