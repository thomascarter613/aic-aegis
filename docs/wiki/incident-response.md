# Incident Response

What happens when Aegis fails.

---

## Purpose

Incident Response defines how Aegis handles operational or safety failures.

---

## Incident Flow

```text
detect
  -> classify
  -> contain
  -> preserve evidence
  -> notify
  -> remediate
  -> review
  -> create tests or controls
```

---

## Incident Types

* policy bypass,
* tool misuse,
* data leakage,
* tenant isolation failure,
* evidence loss,
* memory poisoning,
* high-risk action failure.

---

## North Star

Incidents should improve Aegis controls.
