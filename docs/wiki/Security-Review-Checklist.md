# Security Review Checklist

Security gate before risky changes.

---

## Checklist

* No secrets exposed.
* Tenant scope preserved.
* Sensitive data classified.
* Tool risk class defined.
* Policy checks exist.
* High-risk actions fail closed.
* Evidence redaction considered.
* Logs avoid sensitive data.
* Dependencies reviewed.

---

## North Star

Security review protects trust.
