# Status Reference

Proposed, accepted, active, deprecated, rejected.

---

## Status Values

| Status      | Meaning                   |
| ----------- | ------------------------- |
| Proposed    | Drafted but not accepted  |
| Accepted    | Approved direction        |
| Planned     | Intended but not started  |
| In Progress | Actively being worked     |
| Implemented | Built                     |
| Verified    | Tested against criteria   |
| Deferred    | Postponed                 |
| Rejected    | Intentionally not pursued |
| Deprecated  | No longer preferred       |
| Retired     | No longer used            |

---

## North Star

Status values make project state clear.
