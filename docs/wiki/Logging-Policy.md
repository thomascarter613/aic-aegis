# Logging Policy

Structured logs and sensitive data rules.

---

## Purpose

Logging Policy defines how Aegis logs safely.

---

## Rules

1. Use structured logs.
2. Include run and trace IDs.
3. Do not log secrets.
4. Avoid raw sensitive payloads.
5. Log failures visibly.
6. Use event records for domain history.

---

## North Star

Logs should help debugging without leaking data.
