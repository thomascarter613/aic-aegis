# Tutorial-Add-an-Eval

Eval case creation.

---

## Goal

Add an eval case for a workflow.

---

## Steps

1. Define risk or behavior to test.
2. Create eval input.
3. Define expected behavior.
4. Define scoring rubric.
5. Run eval.
6. Record result.
7. Link result to evidence.

---

## North Star

Evals make AI improvement measurable.
