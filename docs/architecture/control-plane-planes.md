# Control Plane Planes

## 1. Agent Runtime Plane

Owns run lifecycle, state, orchestration, trace IDs, model calls, tool proposals, errors, retries, and event sequencing.

## 2. Memory Plane

Owns working, episodic, semantic, procedural, and evaluative memory.

## 3. Tool Governance Plane

Owns tool registry, tool manifests, capability checks, schema validation, approval requirements, tool execution, and audit logging.

## 4. Policy & Safety Plane

Owns runtime decisions: allow, deny, require approval, sanitize, redact, downgrade, or escalate.

## 5. Evaluation Plane

Owns offline evals, online evals, red-team cases, regression gates, and scorecards.

## 6. Evidence & Audit Plane

Owns evidence packs, trace summaries, action logs, context refs, model refs, tool refs, policy refs, approvals, and exports.

## 7. Learning & Outcome Plane

Owns feedback, failure patterns, improvement recommendations, KPI mapping, and ROI evidence.
