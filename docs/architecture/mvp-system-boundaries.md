# MVP System Boundaries

## In scope

- Single-tenant local development mode
- Run envelope and run event log
- Memory schema and Memory Admission Gate
- Tool registry and broker
- Policy decision service
- Evidence pack generation
- Basic eval runner
- Feedback capture
- Business outcome event model
- Sales/Ops Assistant example workflow

## Out of scope

- production multi-tenancy hardening
- billing
- marketplace
- fine-tuning
- enterprise admin
- complete connector library
- autonomous browser control
- high-risk regulated workflows
