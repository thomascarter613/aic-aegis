# Evidence Pack Model

An Evidence Pack explains what the AI system did, why it did it, what data it used, what rules it followed, what tools it called, and what outcome resulted.

## Evidence Pack sections

- run summary
- actor summary
- input refs
- memory refs
- retrieved context refs
- model calls
- tool calls
- policy decisions
- approvals
- outputs
- eval scores
- business outcome refs
- costs
- errors
- timestamps
