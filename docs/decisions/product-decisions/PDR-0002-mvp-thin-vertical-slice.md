# PDR-0002 — MVP is a Thin Vertical Slice

Status: proposed  
Date: 2026-06-15  

## Context

Aegis has many powerful platform ideas. The risk is building too broadly before proving the core loop.

## Decision

The MVP will be a thin vertical slice through the reliability loop, not a broad implementation of every subsystem.

MVP-A focuses on run, events, tool proposal, policy decision, approval/block, and evidence.

MVP-B adds memory, eval, feedback, and outcome.

## Reasons

This reduces scope risk and makes the demo understandable.

## Consequences

Work packets should prefer thin end-to-end capability over deep subsystem completeness.
