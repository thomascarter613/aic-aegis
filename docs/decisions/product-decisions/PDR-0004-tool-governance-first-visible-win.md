# PDR-0004 — Tool Governance is the First Visible Win

Status: proposed  
Date: 2026-06-15  

## Context

Aegis has several major value propositions. Governed memory is strategically important, but it is harder to demo quickly and convincingly.

Tool governance and evidence produce a clearer first aha moment.

## Decision

The first visible MVP win should be tool governance plus evidence.

The demo should show that AI produces useful output, proposes a risky tool action, Aegis blocks or approval-gates it, Aegis explains why, and Aegis generates evidence.

## Reasons

This makes the product immediately understandable and demonstrates safety, governance, and usefulness in one flow.

## Consequences

Memory remains part of the architecture, but earliest demo prioritizes Run Envelope, Tool Broker, Policy Decision, Approval Gate, and Evidence Pack.
