# WP-E1-001 — Run Envelope and Evidence Schema

## Objective

Define the canonical run envelope, event model, and evidence schema.

## Deliverables

- run envelope JSON schema
- run event taxonomy
- evidence pack JSON schema
- trace identity rules
- acceptance tests

## Acceptance criteria

- Every model call, tool call, memory action, policy decision, approval, and output can be linked to a run ID and trace ID.
